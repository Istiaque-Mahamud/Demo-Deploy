MUSIC FOLDER
Add one MP3 named exactly: birthday-song.mp3
- Only use music you own, created, or have permission/licence to publish (royalty-free or Creative Commons with credit).
- Do NOT use copyrighted songs. Good sources: Pixabay Music, Free Music Archive, YouTube Audio Library.
- Keep it under ~5 MB. Music never autoplays; the visitor taps the music button.
- If the file is missing, the site still works and the button explains why.

YOUTUBE OPTION (default): in script.js, CONFIG.youtubeId holds the YouTube video ID (the part after v= in the link). The official YouTube player plays it when the visitor taps the music button. It needs internet and works on GitHub Pages (https), NOT when double-clicking index.html from your computer. To use an MP3 instead, set youtubeId to "".
